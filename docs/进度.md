## 已知缺口

- **本机号码一键登录**：只有接口，需要开通阿里云号码认证后实现 `api/src/integrations/onekey.ts`。
- **短信**：目前只打印验证码（测试环境会回给 App），需要接阿里云或腾讯云短信。
- **支付**：只有模拟支付，微信支付、支付宝、苹果内购都要等商户号和证书。
- **微信登录、Apple 登录**：代码已写好，没用真实账号验证过。
- **iOS**：从没编译过。iOS 小组件需要在 `app.json` 填团队 ID，并开通 App Group。
- **安卓小组件**不显示常记。
- **导出导入不含照片**（照片走云端同步）。
- 协议文本是草稿，公司名称、邮箱、地址都是占位。
- **图标**等设计师重画，替换 `app/src/assets/icons/retro.ts`。
- 项目还**不是 git 仓库**。
