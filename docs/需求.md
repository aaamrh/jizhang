# 账房 · 第一版需求

> 本文档是唯一依据。改需求先改这里。接口约定见 [api.md](api.md)。

## 定位

微微复古风的记账 App，iOS + Android，公司主体，先上国内。
特色：**家当**（买的东西值不值）、**必要性分析**（钱花在哪一档）、**家庭账本**（一家人一起记，长辈也能用）。

## 1. 记账

账目类型四种：

| 类型 | 钱袋变化 | 计入统计 |
|---|---|---|
| 支出 | 钱袋 − 金额 | 计入该分类支出 |
| 收入 | 钱袋 + 金额 | 计入该分类收入 |
| 转账 | 转出钱袋 − 金额，转入钱袋 + 金额 | 不计入收支 |
| 退款/报销 | 钱袋 + 金额 | 冲减所选**支出分类**的金额，不算收入 |

- 字段：类型、金额、分类（转账没有）、钱袋（转账有转出和转入）、日期（默认今天）、备注。家庭账本**不区分"谁花的"**（见下文"家庭账本"）。
- 支出可以勾上「家当」（计入家当）：填物品名称（默认取备注或分类名），同时生成一件家当。
- **记一笔页下半部的面板**（参照鲨鱼记账，键盘上方只留两行）：第一行是分类图标、一个输入框（只有一行：没输入时显示分类名，输入了就用输入的，没输入就按分类名记；勾上家当时它就是物品名称，不另加说明）、右边金额；第二行是一排浅底小胶囊：钱袋（只留图标和名字）、家当、常记、标签、照片，放不下横着滑（滑动区伸到屏幕边）。胶囊上的字一律用名词（用户要求："options 一般不都是名词吗"），读屏仍念"计入家当""存为常记"。**标签和照片只放一个图标**（一枚签、一台老相机，参照鲨鱼记账）：选了标签后图标后面跟着标签名，有照片时跟着一张小缩略图。再往下是记账键盘（右上角是日期键）。
- 金额正在用记账键盘输入时，下面一道墨线、后面一个闪动的光标；写备注时系统输入法弹起，记账键盘收起，金额变淡；**点一下金额就收起输入法、回到记账键盘**。金额占第一行右半边、整行高度，点金额附近都算；打开面板、换分类时默认就是金额在输入。
- 点分类后记账面板 150ms 内升起，键盘马上能按（不用弹簧动画）。
- 记账面板里的控件分两种样式：**选择项**（钱袋）是描边胶囊「钱袋 现金 ▾」，点开选；**勾选项**（家当、常记）是带方框的胶囊，勾上后方框填墨色、胶囊淡墨底（选中一律用墨色，不用朱红）。
- **金额显示**：整数不带小数（120,000），有零头去掉末尾的 0（12.5、3.02）。输入时不受影响。
- 编辑、删除：删除关联了家当的支出时，家当一起删，删前提示；家当已卖出、丢失或损坏的，不允许这样删（直接说明原因，不弹确认）。
- **列表里的账目**（流水、搜索、盘账明细）：点开编辑；**左滑**露出红色“删除”（先确认）；**长按**弹出菜单：编辑 / 再记一笔 / 存为常记 / 设为定时记账（支出、收入才有）/ 删除。菜单用自己的底部弹层（安卓系统弹窗最多 3 个按钮）。
- 转账页提示：信用卡还款、借钱给别人、还别人钱，都在这里记。
- **常记**（免费）：把常用的一笔存成常记，比如"理发 30""上班交通 2"（名称、支出/收入、分类、金额、钱袋，可选备注）。用法：记一笔页分类网格上方是常记区：胶囊按内容宽度自动换行，最多露出 3 行，多了在框内滚动，标题行右侧「管理」固定不动；点一下按今天记上，长按弹出编辑 / 删除；长按底部「记」按钮弹出常记列表，点一下就记。都会盖章并提示"已记"（不带撤销：记错了长按那笔删掉）。记一笔时勾上「常记」，保存时按名称新建或更新；账目的 ⋯ 菜单里也可以"存为常记"。在"掌柜 → 常记"里增删改、拖动排序，左滑删除。新用户第 3 次记账后提示一次"长按「记」可以快速记常记"。按账本保存、随账本同步和导出导入。桌面小组件暂不显示常记。流水首页不放常记。
- **标签**（免费）：跨分类的记号，比如"云南旅行""装修""报销""孩子"。一笔最多 3 个，每个最多 10 个字。样式就是常记那种浅底胶囊（流水行里矮一号）。
  - 记：记一笔面板第二行点标签图标，弹出选标签：最近用过的在前，点一下选上 / 取消，也能写个新的。选好的标签直接显示在第二行，点它再改。"再记一笔同样的"、常记都带上标签。转账不带标签。
  - 看：流水、搜索、盘账明细里，标签跟在标题后面（最多露两个，多的写 +1），点标签进标签页。
  - 标签页：这个标签的所有账，不分月份；合计花了多少（支出 − 退款）、有收入也列出、从哪天到哪天、几笔；跨月时分月列出。右上角 ⋯：改名（改成已有的名字就合并）、删除标签（账不删，只是去掉这个标签）。
  - 盘账：分类排行下面"按标签"，这段时间每个标签花了多少，点开进标签页；一笔两个标签两边都算，所以不显示占比；只在"全部"时显示（不受必要性筛选影响）；右下"全部标签"列出所有标签。
  - 搜索也能按标签名搜到。导出 Excel 多一列"标签"，备份、同步都带上。家庭账本里不显示别人的标签。
- **账目照片**（免费）：小票、发票、报销凭证。记一笔第二行点照片图标：拍照 / 从相册选；有照片时还能看大图、去掉。照片压缩后先存本机，登录并开启同步后上传，换手机能看到（同家当照片）；家庭账本里不显示照片；导出的备份文件不含照片。删账时照片（本机和服务器上）一起删。流水行里有照片的账在标题后面有个小相机。
- **定时记账**（免费；原叫"周期记账"，2026-11-20 改名）：房租、工资、会员续费这类固定的账，到日子自动记一笔。在"掌柜 → 定时记账"里添加，表单从上到下：支出 / 收入 → **什么时候记**（最要紧，放最上面）→ 金额、备注 → 分类 → 钱袋；多久一次（每天 / 每周几 / 每月几号 / 每年几月几号，周几、几号、几月都能选，不选就跟开始日期同一天）、从哪天开始（从这天起第一个对得上的日子记第一笔）、可选结束日期。每月 29–31 号的，没有这一天的月份记在月底；2 月 29 日的每年周期，平年记 28 日。
  - 打开 App、回到前台时把到日子的补记上，提示"定时记账自动记了 N 笔"。开始日期在今天之前的，保存时把之前的一起补上（保存前告诉用户会补几笔）。
  - 自动记的账和手记的一样（能改、能删），删掉的不会再补回来；打开时写着"这笔是定时记账自动记的 · 去看看"。自动记的不算进连续记账天数，也不算"今天记过账"（记账提醒照常响）。
  - 可以暂停，恢复后从当天接着记，暂停期间的不补。分类或钱袋不在了：这条自动暂停，提示是哪条。删掉周期，已经记下的账留着。
  - 只在我的账本里；随账本同步和导出导入；两台手机同时补记不会重复（自动记的账 id 由周期和日期算出）。
  - **入口**（定时记账是核心功能，不能只藏在掌柜里）：
    1. 记一笔：点键盘上的日期键，日期弹层最上面一行"重复"：不重复 / 每天 / 每周 / 每月 / 每年。选每周下面出一排"一 二 三 四 五 六 日"，每月出一排可横划的 1–31，每年出两排（1–12 月、几号），默认是这笔的日期，点了就按点的。下面一行小字说清楚"每月 5 日自动记一笔，这一笔算第一次，下次 12月5日 周六"（日期在以前的说"保存后补记到今天，共 N 笔"），"要停或改去“掌柜 → 定时记账”"。选了以后日期键上多一行小字（如"每月 5 日"）。这一笔算这一期（这周 / 这个月 / 这一年）的，从下一期记起：11 月 20 日记的房租选"每月 25 号"，下次是 12 月 25 日，不会 11 月 25 日再记一笔。保存后提示"以后每月 25 日自动记这一笔"。只有新记的支出、收入能选；改账时不出现。
    2. 已经记过的账：长按菜单、编辑页 ⋯ 菜单里"设为定时记账"，打开定时记账表单，内容照这一笔填好、默认每月，这一笔算第一次。
    3. 首页快捷入口"定时"；三天内有要自动记的，快捷入口下面一行小字"后天自动记 房租 -3,000"，点开定时记账。
    4. 流水里自动记的账，名字旁边一个小循环记号。
- **再记一笔**：账目详情里"再记一笔同样的"，复制类型、金额、分类、钱袋、备注，日期改为今天，打开记一笔页确认。

## 2. 钱袋

| 种类 | 例子 | 余额显示 |
|---|---|---|
| 资产类 | 现金、银行卡、支付宝、微信、借出（应收） | 余额 |
| 负债类 | 信用卡、花呗、借入 | 欠款（余额为负时显示正数） |

- 余额 = 初始余额 + 收入 + 退款 + 转入 − 支出 − 转出。
- 每个账本有自己的钱袋。默认：现金、银行卡、支付宝、微信；家庭账本默认只有"家用"。
- 新增、改名、归档；有账目的钱袋只能归档。
- **校准余额**：输入"现在实际是多少"，自动反推初始余额，不产生账目。

## 3. 分类

- 有歧义的领域按必要程度拆开，每个分类的档位天然清楚，记账时不问必要性。只做一级分类。
- 图标：约 120 个 Lucide 线描图标（按 餐饮、交通、居家、购物、娱乐、健康、学习、人情、金融、其他 分组），或"汉字印章"。8 个复古色。新建时按名称推荐图标。
- 颜色和档位无关；记账界面不显示档位。
- 记一笔页分类网格最后一格是"＋ 添加"：直接新建一个当前类型的分类（原来叫"设置"、进分类管理，加号和文字对不上，2026-11-20 改）。管理分类在"掌柜 → 分类"。
- 每个账本有自己的分类。默认分类 id = uuid v5(账本 id, 分类标识)。
- **默认支出分类**：
  - 必需：住房、水电燃气、通讯网费、通勤、买菜、医疗、保险、人情往来
  - 弹性：外出就餐、打车、日用、服饰、数码、聚会请客、育儿、宠物、学习
  - 享受：零食饮品、娱乐、旅行、烟酒、游戏
- **默认收入分类**：工资、奖金、副业、理财收益、红包礼金、变卖（系统用，不能隐藏）、其他。
- 管理：新建支出分类时选一次档位（默认弹性）；隐藏；合并；拖动排序。

## 4. 复盘（月底回头看）

- 页面上一句话说明：回头看看这个月花得值不值：每笔标记必要或非必要。
- 每月从弹性 + 享受两档支出里，挑金额最大的 8 笔还没标记的，只有两个选项：**必要 / 非必要**。
- "下次再说"：直接离开，已标记的保留，没标记的下次还会出现。
- 结束页显示"必要"和"非必要"的占比，语气温和。已复盘的列在页面下方，可以改。
- 旧版本的"值 / 一般 / 悔 / 跳过"启动时迁移：值→必要，悔→非必要，一般和跳过→没复盘。

### 必要性（盘账筛选用）
- 复盘标记过的，以标记为准；
- 没标记的按分类档位推定：必需→必要，享受→非必要，弹性→**待定**（提示去复盘）。

## 5. 家当

- 来源：记支出时勾上「家当」，或手动添加（不动钱袋）。
- 列表分"持有中"和"已出手"：名称、买价、持有天数、日均。
- 详情：持有天数（买入当天算第 1 天）；日均 = (买价 − 卖价) ÷ 持有天数；使用次数；每次 = (买价 − 卖价) ÷ 使用次数；持有中提示"再用 180 天，日均降到 ¥x"。
- 操作：卖出（生成"变卖"收入，显示盈亏）、丢失、损坏、撤销、删除（仅持有中）。
- **照片**：拍照或从相册选，压缩到长边约 1280 的 JPEG，先存本机立刻显示；登录并同意同步后在后台上传到云端，账目里只同步照片的云端 id，别的手机打开时按需下载并缓存。没登录时照片只在本机。换照片、删照片会顺手删掉云端旧文件。导出的备份文件不含照片。

## 6. 流水（首页）

- 顶部固定不滚动，尽量紧凑（360×640 的小屏也能露出 4 行以上账目）：最上面居中是当前账本名「我的账本 ▾」（点开切换账本，最后一项「管理账本…」），右上角是搜索；下面左边小字年份、月份（标题字号）（点开快速跳年月）；右边本月支出、收入、结余（十几万、上百万自动缩小字号，不和月份挤在一起）。
- 一条细线：预算进度。下面一行左边"预算 ¥500，还剩 ¥320 / 超出 ¥2,070"：字是墨色，只有还剩（绿）、超出（红）的金额带颜色；右边灰字"调整 ›"，整行点开预算页。没设预算时只有一行灰字：左"还没设预算"，右"去设 ›"（预算一直有效，不按月设）。
- 一行：🔥火苗 + 连续记账 N 天 · 在攒的心愿（如"旅行基金 62%"，没有就是"立个心愿"，点开心愿）· "今天没花钱"。
- 快捷入口：复盘、心愿、定时（1 月份另加去年的年账）。预算不放这里（在上面进度条那一行）。下面可能有一行定时记账提示（见第 2 节定时记账）。
- 只有账目列表滚动：按日分组，家庭账本里每笔显示是谁记的。中间的"记"按钮记一笔，记完屏幕中间盖一枚"入账"白文印：快速压下去、不回弹，停一会儿再慢慢淡掉。

### 盘账（统计）
- 周 / 月 / 年切换；必要性筛选：全部 / 必要 / 非必要 / 待定，筛选影响支出合计和分类排行（收入不受影响）。
- 必要性占比条（点图例也能筛选）；分类排行每一行点开看这段时间这一类的每一笔（见下文「看每一笔」），点某一笔可编辑。
- 家庭账本另有"谁记了多少"（这个月每人记了多少支出）；「不含家当」开关；入口：年账、复盘。
- **周视图**（原来的周账并进来了）：三个数下面一行"比上周少花 ¥120 · 记了 5 / 7 天"（和上周比的口径跟上面的支出一样：同样的必要性筛选、同样的不含家当；上周没花钱不比），分类排行下面多一块"最大的一笔"。只在我的账本里有。

### 看每一笔（盘账、年账通用）
- 点分类排行的一行、点必要性色条（或图例）、点年账的月份柱子，都从底部弹出同一个明细面板：半屏打开，按住顶部上拉全屏、下拉关闭。
- 标题如"娱乐 · 本周 ¥320 · 5 笔"、"非必要 · 2026年 ¥4,800 · 36 笔"、"11月 · 2026年 ¥3,200 · 58 笔"。
- 每一行：日期、备注、钱袋、谁记的（家庭账本）、金额；左滑删除、长按出菜单、点开编辑。按必要性看时按金额从大到小，其余按日期从新到旧。
- 年账顶部也有 全部 / 必要 / 非必要 / 待定 筛选，影响支出合计和分类排行，和盘账一致。

## 7. 养成记账习惯（不发任何奖励）

### 连续记账天数
- 某天算"记过账"：当天有日期为这一天的账目（任何类型、任何账本），或点了"今天没花钱"。
- 补记昨天自然算数：今天补一笔日期是昨天的账，昨天就算记过。
- 首页显示"连续记账 N 天"，前面一簇会动的**火苗**，天数越多火越旺（像游戏里的连杀）：火星 1–6 天（金色）、火苗 7–20、旺火 21–29、烈火 30–99（朱红）、燎原 100 天以上（深红外焰、亮金芯，像烧透的炭）；越往上越大、动得越快、飘的火星越多（一到三颗）。火苗是 SVG（`components/Flame.tsx`），一比一照搬用户给的 CSS 火焰：三团火都是旋转 45° 的圆角方块（左上角尖，圆角 0 40% 60% 40%），横向压到 0.8，左右两团小的伸到两侧；每团外面一圈同色光晕，中间一团从角上往下的径向渐变；中间 3 秒一轮上下伸缩，左右两团按 3 秒、2 秒的节奏歪一下再回来，底部一团亮光 2 秒一明一暗，火星往上飘；几路节奏互不整除，不会整齐重复。系统开了"减弱动态效果"时火苗不动。
- 今天还没记：火苗变灰、冒一缕烟，写"已连续 N 天 · 今天还没记"，不立刻算断，不说"要断了""失败"。记一笔或点"今天没花钱"就重新点亮。断了以后不提断了几天，回到灰火星，写"今天记一笔，点起火苗"。
- **关口庆祝**：连续到 7、21、30、100、365 天的那天，记完那一笔（"入账"章落下之后）弹一张小卡片：大火苗 + 四个字（七日不辍、习惯已成、持之以恒、百日之功、岁岁不辍）+ 一句白话 + 一句古话，3.5 秒后自己收起，点一下也收起。同一个关口只弹一次。文案在 `app/src/utils/streak.ts`。
- 另显示"累计记账 N 天"和"最长连续 N 天"（在"掌柜"页；最长连续断了也留着）。
- 只在本机计算；登录后"今天没花钱"的标记随账本同步，多台手机看到的一致。

### 今天没花钱
- 当天还没记账时首页出现按钮，点了算当天记过账，显示"零花费日，又省下一天"一类的话。可以撤销。

### 记账提醒
- 首次打开时问"你一般几点有空记账？"：午饭后 12:30、下班路上 18:00、晚饭后 20:30、睡前 22:00，或自己选时间；也可以"先不用"。

### 每周日看账

## 9.1 攒钱目标与心愿（所有人可用）

- **立目标**：名字、目标金额、期限（可不设，默认三个月后）。每个目标自动建一个专属**储钱罐**（钱袋种类"储钱罐"），只在钱袋页"储钱罐"一栏和转账时出现，不出现在记账选钱袋里。
- **存一笔 / 取出**：就是往储钱罐转账（预填好的转账页），不算支出，不影响收支统计。目标都建在主账本里。
- **进度** = 储钱罐余额；有期限时提示"离期限还有 N 个月，每月存 ¥x 就够"，过了期限提示"还差 ¥x，再加把劲"。
- **两步：攒够 → 圆梦**。攒钱不是终点，把钱用在想做的事上才是。
  1. **攒够**：储钱罐余额第一次 ≥ 目标（记账保存后、打开心愿时检查），冻结日期和金额，弹出牌匾"攒够了"，牌匾挂进如愿，但**还没盖章**：颜色淡一点，角上写"待圆梦"，心愿顶部提示"钱攒够了，去把它变成日子里的光吧"。之后取出用掉，牌匾也一直留着。
  2. **圆梦**：点"圆梦"（攒够后从储钱罐取钱时也会轻轻问一句"是去实现它吗？"），可以写一句话（40 字内）、配一张照片（同家当照片：先存本机，登录同步后上云，不导出），点"盖章圆梦"：一枚朱红"圆梦"篆刻印从上方压到牌匾右下角，轻轻一弹、印泥晕开（系统减弱动态效果时直接出现），记下圆梦日期。已圆梦的牌匾点开放大，下面显示照片和那句话。
- **先收起来**：不想继续攒的目标可以收起来，留档但不进心愿，储钱罐里的钱可随时转出。不用"放弃""失败"这类字眼。
- **文案**：一句古诗（霞鹜文楷）+ 一句白话（小字）+ 出处（更小）。温和，不苛责，"要有诗和远方，不只是攒钱"；不用"放弃""失败"这类字眼。每个时刻一句固定的白话、一组古诗，随机轮换且不连着重复。全部在 `app/src/utils/goals.ts` 的 GOAL_COPY 里，改文案只改这一处：

| 时刻 | 白话 | 古诗（轮换） |
|---|---|---|
| 立目标 | 想要的，值得慢慢攒 | 千里之行，始于足下（老子）· 不积跬步，无以至千里（荀子）· 合抱之木，生于毫末（老子）· 长风破浪会有时，直挂云帆济沧海（李白） |

| 过半（这一笔刚跨过一半） | 过半了，最难的一段已经走完 | 千淘万漉虽辛苦，吹尽狂沙始到金（刘禹锡）· 锲而不舍，金石可镂（荀子） |
| 攒够了 | 攒够了，攒钱是为了好好生活 | 人生得意须尽欢，莫使金樽空对月（李白）· 花开堪折直须折，莫待无花空折枝（杜秋娘）· 会当凌绝顶，一览众山小（杜甫） |
| 圆梦 | 此行不虚，愿你常有出发的勇气 | 春风得意马蹄疾，一日看尽长安花（孟郊）· 两岸猿声啼不住，轻舟已过万重山（李白）· 仰天大笑出门去，我辈岂是蓬蒿人（李白）· 采菊东篱下，悠然见南山（陶渊明） |
| 没攒够先取出来用 | 先顾眼前也没关系，目标一直在 | 天生我材必有用，千金散尽还复来（李白）· 且将新火试新茶，诗酒趁年华（苏轼）· 山重水复疑无路，柳暗花明又一村（陆游） |

  牌匾上写：目标名、金额、用了多久（如"三月成"）、攒够的日期；圆梦后右下角盖一枚**白文方印**：红底，四字印文"刻"出来透出纸色，从右列往左列读，微斜；字和边上有斑驳、边框断两三处，像印泥没压匀，每块匾的斑驳不一样（按匾名和日期生成）。印文"不负韶华"（`app/src/utils/seal.ts` 的 `SEAL_PHRASE`）。盖章动画是压下去就停住，不回弹、不晕开红圈。

- 目标随账本同步（接口实体 `goals`），也在导出导入里。

## 11. 账本与家庭

产品只针对**个人和小家庭**，不做企业、项目这类复杂账本。

- **账本**：**我的账本**（每人一个，只有自己能看，不能删，记账都记在这里）和**家庭账本**（大掌柜创建，家人免费加入）。**一个人可以同时在好几个家庭账本里**（比如和另一半的"我们家"、和父母的"爸妈家"），大掌柜也可以建好几个。不做多账本 / 专项账本（装修、旅行、生意这类）。
- **只在自己的账本里记账**。家庭账本本身不记账，它是一家人各自账本的汇总。**每个人创建或加入一个家庭时，自己选一个共享开始日期**（到日；默认今天，不能晚于今天，可以早于加入那天），**这天起记的账全部汇进这个家庭账本**（按账目日期；之前的不汇；不做"只自己看"）。在好几个家庭里时，每个家庭各按自己为它选的日期汇总，同一笔账会出现在每个家庭里。转账不汇，那是各人钱袋之间的事。
- 选日期的地方写明：从这天起你记的支出、收入和退款会汇进「某某」，这个家庭的人都能看到；转账不算；选早一点，以前记的账也会汇进去。建好或加入后暂不能改日期（要改得退出再加入）。
- 家庭账本里看：本月汇总的收支、每一笔（写着谁记的）、分类统计、头像那一排和每人记了多少、按人看。**钱袋余额不汇总，不设家庭预算**；预算、年账、复盘、心愿、家当都只针对我的账本（盘账周视图的比上周、记账天数、最大的一笔也是）。
- 每个家庭最多 10 位成员。只邀请装了账房、有账号的家人，不做没账号的"家人档案"。

| 角色 | 能做什么 |
|---|---|
| 管理员（创建者） | 看家庭账本、邀请 / 移除成员、改名、换封面、解散 |
| 成员 | 看家庭账本、退出 |

- **只认"谁记的"，不分"谁花的"**（产品特点，见 docs/决策.md）：每笔账归记账的人。首页家人头像、盘账的按人统计都是"谁记了多少"。
- **退出或被移出**：在家期间汇进去的账留在家庭账本里，之后记的不再汇；他自己看不到这个家庭账本了。
- **创建者的大掌柜过期**：家人的新账不再汇进来；会员期间所有人的账都还在，创建者自己照常能看（他自己的账照常汇进）；其他家人看不到这个家庭账本，各自的账本不受影响；不能发新请帖。**续费后恢复原样，断档期间家人记的账补进来**。
- **解散**：家庭账本消失；每个人自己的账本不受影响。
- 首页"切换账本"抽屉列出我的账本和我在的每个家庭账本，选哪个首页就看哪个；盘账顶部的分段（我的账本 / 各家庭）跟着同一个选择。"管理账本"页列出每个家庭账本，下面始终有"新建家庭账本"和"用邀请码加入"。

### 新建家庭账本（大掌柜）
1. **还不是大掌柜**：先看一页示意（几个家人头像、"妈妈记的 买菜"这样的账、能做什么），再决定开通；也可以"收到请帖？直接加入（免费）"。
2. **起名 + 封面**：名称有建议（我们家、一家人、小家、爸妈家、柴米油盐），封面是一本**线装账簿**：选一种纸色（靛蓝、赭石、松绿、藕荷、缃色、黛青），账本名竖写在左上角的签条上，右边是四眼钉的装订线；起名时上方实时预览。账本列表和首页"切换账本"抽屉（两本账都画成小账簿，我的账本默认靛蓝、家庭账本默认松绿）、请帖、账本页都显示封面。管理员以后可以在账本页点封面更换。
3. **共享开始日期**：创建者自己的账从哪天起汇进来（见上）。
4. **写请帖**：建好直接进邀请页。

### 家庭邀请（请帖）
1. 管理员点"邀请家人"。
2. 生成**请帖**：朱红洒金纸、双金线框、四角回纹，写着"请帖"、账本封面、"某某 诚邀您 共入「我们家」"、8 位邀请码、二维码、几月几日前有效。7 天有效，可多人使用直到满员。
3. 分享：**把请帖截成图片**用系统分享发到微信；也可以"发文字链接"（链接 + 邀请码）或"复制邀请码"。
4. 收到的人：点链接打开 App 的加入页（没装 → 网页落地页）；或在"加入家庭账本"里输入邀请码（输满 8 位自动查）。加入页先展示同一张请帖，下面选**共享开始日期**（见上），再加入。
5. 没登录：点"登录后加入"，登录完回到加入页自动接着加入；没同意云同步的，点"同意云同步，并加入"。加入后提示"欢迎加入「某某」"，并切到这个账本。
6. 发出去的请帖列在邀请页，可以作废（先确认：没加入的进不来，已加入的不受影响）。

### 家庭账本的流水
- 账本顶部一排家人头像（印章样式的圆，里面是名字第一个字；大掌柜一圈金边），头像下面是这个月他**记了多少**，按记得多少排序。点一个人只看他记的账，再点一下或点"全部"恢复。家人档案没有账号、不会记账，不在这一排。
- 头像那一排**始终显示**：只有自己一个人时就是自己，最后一个是"＋邀请"（管理员才有）。
- 首页的"记"照常记到我的账本；在家庭账本页面点"记"也一样，记完自动汇进来。

### 账本页（家人）
- 顶部：封面、账本名、几位家人、我是管理员还是成员。
- 只有管理员能看到：邀请家人、改名、解散。成员只有"退出账本"。
- 移出、退出、解散，确认框都写清楚后果：谁还能看到、账目留不留、能不能恢复。解散要按住“按住解散”约 1.5 秒。
- 创建者大掌柜过期后：见上面"创建者的大掌柜过期"。

## 12.8 日期选择（2026-11-20）

- 选日子（记一笔、定时记账开始结束、家庭账本共享开始日期、盘账选周）：一个月一页，‹ › 或左右滑动换月，点标题逐级上翻到月、年。选中的那天是朱文框（朱红细框，数字墨色），今天是数字下面一粒墨点。点日子、点底下的"昨天""今天"都只是选中，按"确定"才定下、关面板；下拉或点外面算没改。
- 选月份、年份（首页跳月、盘账、年账）：点了就定，底下一个"本月"/"今年"。
- 记账日历里选中的那天也是朱文框。

## 12.9 确认与撤销（2026-11-20）

- **删除先确认，不做撤销**：删一笔账、常记、标签、定时记账都先弹确认框（危险按钮红字）。点常记"已记"也不带撤销，记错了删掉那笔就行。"已删除 · 撤销"这种轻提示做过（`removeWithUndo`），用户觉得一般删除用不着、太复杂，但动画不错，代码留着，以后合适的地方再用。
- **弹窗的按钮**：取消是普通描边；普通确认是墨色实心；危险操作（删除、移出、退出、作废……）是红字描边，和页面上的"删除"按钮一样，按钮写动作（"删除""解散"），不写"确定"。朱红实心不再出现在弹窗里（朱红是"记"和每页主按钮的颜色，不代表危险）。
- **回不去的操作要按住**：注销账号、解散家庭账本、导入备份覆盖账本。按钮写"按住注销""按住解散""按住覆盖导入"，按住约 1.5 秒，红色像印泥一样从左铺满才生效，松手就取消。读屏时双击直接生效。

## 13. 同步

- 本地优先：先写本地，立即生效，没网也能记。
- 时机：打开 App、记账后约 2 秒、下拉刷新、切回前台；前台每 30 秒一次。
- 服务器按账本给改动编递增版本号；一次请求同时上传和下载。
- 冲突以最后修改时间为准；删除只做标记；余额、统计各端现算。
- 同步的数据：钱袋、分类、账目、家当、预算、"今天没花钱"标记、常记、攒钱目标。账本、成员、邀请走专门接口。
- 服务器不解析账目内容，后台没有查看账目的界面。

- 下拉刷新：转圈至少 0.6 秒、最长 15 秒一定收回（同步失败、断网也收回）；刷新期间暂停左滑删除，左滑要水平拖过 16 才触发，不和下拉抢手势。

## 13.1 开屏广告（预留，现在没有，以后接）

- 只有开屏一处广告，记账、看账的页面里一律不放广告（用户原话"记账应用内没有会员，开屏会员还是要有的啊"，这里的"会员"指广告）。现在还没有广告合作，**不接广告 SDK、不写占位代码**；接的时候按下面做。
- 规则：只在冷启动时放，同一台手机几个小时内最多一次；从桌面小组件、记账提醒、长按「记」进来时不放；必须有"跳过"，最长 3 秒；不做"摇一摇"、扭动跳转这类容易误触的形式；大掌柜和免广告会员不放。最好有一个服务器开关，能随时关掉。新用户也放（原提议"前 7 天不放"，用户去掉了）；屏蔽借贷类广告等真接广告时再说。
- 免广告会员（青花卡）：只免广告，比大掌柜便宜；大掌柜包含免广告。两档各算各的到期日，任一档有效就不放。卡面白底钴蓝青花、缠枝莲纹，和绛紫鎏金的大掌柜一眼能区分。随广告一起上线（没有广告时卖"免广告"没有意义）。
- 接的时候要一起做：开屏广告 SDK 多半要在 App 启动的原生层接（具体看选哪家）；广告 SDK 只能在用户同意隐私政策后初始化（首次同意页已经有了）；改隐私政策（加广告 SDK 和它收集的设备标识）、用户协议（去掉"无广告"）、首次同意页的文案，以及大掌柜页底下"……这些功能永远免费，没有广告"那句。

## 14. 大掌柜（VIP）

  - **导出 Excel**："导出导入"页里。把我的账本每一笔导成 .xlsx（日期、类型、分类、金额、钱袋、转入钱袋、备注、复盘；支出是负数，直接求和就是结余），用系统分享发出去，Excel、WPS 都能打开。

## 15. 支付

- 流程：选方案 → 创建订单 → 调起支付 → 渠道回调 → 订单已支付 → 加大掌柜天数。
- 同一订单回调多次只生效一次；App 回到前台主动查订单；后台可手动补单。
- 退款：扣回对应天数（最多扣到当前时间）。苹果退款通知自动处理，安卓由客服在后台处理。
- 渠道：iOS 苹果内购；安卓微信支付、支付宝。**第一版**完成订单、发放、后台和"模拟支付"（仅测试环境）；真实渠道拿到商户号和证书后接入。

## 16. 其他功能

- **导出/导入**：导出当前账本为 JSON；导入时选账本，提示"将覆盖该账本的全部数据"。超过 30 天没导出、也没登录同步时首页提醒。
- **应用锁**：冷启动或后台超过 1 分钟回来时，验证指纹、面容或手机密码。
- **搜索**：当前账本内按备注、金额、分类查找。
- **桌面小组件**（iOS、安卓）：显示今日已花、本月已花，点"记一笔"直接打开记账页。
- **首次打开先同意协议**：第一次打开（以及协议有实质改动、版本号加一后）先显示"欢迎使用账房"：几句要紧的话（不登录也能用；开同步后账目和照片存到服务器；会上报安装编号、系统、版本和出错信息，不含账；权限用到才问）、《用户协议》《隐私政策》可点开看全文、"同意并开始" / "不同意"。不同意：提示没法使用，安卓上可以退出，iOS 停在这页。**同意之前不向服务器发送任何东西**（应用商店审核要求）。
- **匿名统计**：同意协议后，每次启动上报随机安装 id、平台、版本号，登录后附带用户 id。
- **出错兜底和上报**：页面出错时不白屏，显示"这里出了点问题，你的账都在"和"回到首页"；闪退前把出错信息记在本机。同意协议后发给服务器（只有出错类型、说明和代码位置，不含账），后台"出错"页能看最近 200 条。
- **升级保护**：App 升级要改本机数据库时，先在 App 自己的目录里备份一份（只留最近 2 份）；升级在一个事务里做，出错整体回滚，账停在升级前的样子，并提示更新到最新版或联系我们。
- **版本更新**：有新版弹窗可关闭；低于最低支持版本强制更新。
